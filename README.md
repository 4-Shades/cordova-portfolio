# Chaim Joseph Cordova — Portfolio

My personal portfolio and blog, built with [Next.js](https://nextjs.org/) and [Tailwind CSS](https://tailwindcss.com/).

## Development

Install dependencies:

```bash
yarn
```

Run the development server:

```bash
yarn dev
```

Open [http://localhost:3000](http://localhost:3000) to view it.

## Structure

- `data/siteMetadata.js` — site info, social links
- `data/projectsData.ts` — projects shown on the projects page
- `data/authors/default.md` — author/about info
- `data/blog` — blog posts
- `public/static` — images and other assets
- `app` — pages and routes

## Build

```bash
yarn build
```
